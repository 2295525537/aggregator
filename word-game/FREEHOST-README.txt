========================================
  免费廉价主机部署专用说明
========================================

【常见 403 原因】
免费/廉价主机常因以下原因拒绝访问：

1. 禁用 .htaccess（已处理）
   本项目已彻底删除所有 .htaccess 文件，
   改用 PHP 内部逻辑保护数据，无需任何 Apache 配置。

2. 主机只支持 .html 不支持 .php
   这类主机无法运行本项目的 PHP 后端，请换主机。
   自测方法：访问 http://你的域名/check.php
   - 能看到 PHP 输出的检测页 → 支持 PHP
   - 显示 403 / 404 / 下载提示 / 原代码 → 不支持 PHP

3. 文件权限不正确（最常见）
   上传后必须设置权限（FTP 软件或主机面板）：
   - 所有目录：  755 (rwxr-xr-x)
   - 所有文件：  644 (rw-r--r--)
   - data 目录： 755 或 777（必须可写，否则数据无法保存）

4. 文件所有者不正确
   FTP 上传后，文件归属会变成 FTP 账户，
   但 Web 服务以 apache / www-data / nginx 用户运行。
   在主机面板找"修复文件权限/所有权"功能一键修复，
   或联系主机商。

5. 网站根目录指向错误
   确认主机面板"网站根目录 / DocumentRoot"指向
   包含 index.php 的那一层，而不是上一层。

========================================
【免费主机部署步骤】
========================================

1. 用 FTP（如 FileZilla）或主机面板的"文件管理器"
   上传整个 word-game 文件夹内的所有内容
   到网站根目录（通常是 public_html / wwwroot / htdocs）

   ★ 注意：是上传文件夹"内部的内容"，
     不要上传 word-game 文件夹本身。
     即根目录下应该直接看到 index.php、api.php

2. 修改所有目录权限为 755，文件权限为 644
   特别地，把 data 目录权限改为 777

3. 浏览器访问：
   http://你的域名/check.php
   全部显示 OK 即可正常使用

4. 学生端：  http://你的域名/
   教师后台：http://你的域名/dashboard.php
   教师密码：7405211

========================================
【仍然 403 怎么办？】
========================================

A. 极简自测：在根目录新建一个 test.html，
   内容随便写"hello"，访问 http://你的域名/test.html
   - 能打开 → 主机能访问静态文件，问题在 PHP 或权限
   - 也 403  → 主机根本没把你指向的目录当根目录，
              去主机面板改"网站根目录/DocumentRoot"
              指向 public_html（或上传到的目录）

B. 再测 PHP：在根目录新建一个 info.php，
   内容：  <?php phpinfo(); ?>
   访问 http://你的域名/info.php
   - 看到 PHP 信息页 → 主机支持 PHP
   - 403/404/下载提示 → 主机不支持 PHP，
                       换支持 PHP 的免费主机
                       （如 infinityfree.com、000webhost.com）

C. 把所有文件权限设为 644，所有目录设为 755，
   data 目录设为 777 后再试。

D. 联系主机商客服，告诉他们"我上传的 PHP 网站
   访问提示 403，请帮我检查 Apache 配置和
   文件所有权"。免费主机一般 24 小时内回复。
