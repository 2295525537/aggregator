========================================
  AI 单词闯关游戏 - 虚拟主机部署版
========================================

【支持环境】
本项目同时支持两种部署方式：

▶ 方式一：PHP 虚拟主机（推荐，无需安装环境）
  适用：大部分虚拟主机（支持 PHP 5.6+ 即可）
  只需上传所有文件到网站根目录即可使用

▶ 方式二：Node.js 服务器
  适用：有 Node.js 环境的服务器
  运行 start.bat (Windows) 或 ./start.sh (Mac/Linux)

========================================
【PHP 虚拟主机部署步骤】
========================================

1. 将所有文件上传到虚拟主机网站根目录
   （通常是 public_html、wwwroot、htdocs 等）

2. 确保 data 目录有写入权限（755 或 777）
   - 如果数据保存失败，在虚拟主机面板设置 data 目录权限为 755

3. 先访问检测页面确认环境：
   http://你的域名/check.php
   - 全部显示 OK 即可正常使用
   - 如有失败项，按页面提示解决

4. 浏览器访问：
   学生端：  http://你的域名/
   教师后台：http://你的域名/dashboard.html
   教师密码：7405211

========================================
【文件说明】
  index.html        学生端页面
  dashboard.html    教师后台页面
  api.php           PHP 后端接口（虚拟主机核心文件）
  server.js         Node.js 后端（仅 Node.js 部署需要）
  package.json      Node.js 依赖（仅 Node.js 部署需要）
  .htaccess         Apache 配置（保护数据目录）
  start.bat         Windows 一键启动（Node.js 方式）
  start.sh          Mac/Linux 启动脚本（Node.js 方式）
  public/css/       样式文件
  public/js/        前端逻辑
  data/             数据存储目录（需写入权限）

========================================
【功能说明】
  - 学生端：听音选词 / 看图猜词 / 词义匹配 闯关游戏
  - AI 自动分层：C入门层(<60%) / B基础层(60-85%) / A巩固层(>85%)
  - 分层个性化任务单 + AI自动批改 + 错题本
  - 教师后台：实时学情仪表盘 + 分层统计柱状图

========================================
【常见问题】

Q: 上传后页面空白或报错？
A: 检查文件是否上传完整，特别是 api.php 和 public/ 目录

Q: 学生数据无法保存？
A: 将 data 目录权限设置为 755 或 777

Q: 教师后台无法登录？
A: 确认密码为 7405211，检查 api.php 是否可正常访问

Q: 想清空所有数据？
A: 删除 data/db.json 文件，刷新页面会自动重建
